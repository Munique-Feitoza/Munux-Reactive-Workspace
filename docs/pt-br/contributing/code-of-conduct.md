## 🌟 Formas de Contribuir

- 🐛 **Reportar Bugs**: Encontrou um problema? Avise-nos!
- ✨ **Sugerir Funcionalidades**: Tem uma ideia? Adoraríamos ouvi-la!
- 📝 **Melhorar a Documentação**: Ajude a tornar nossos docs melhores!
- 🔧 **Enviar Código**: Corrija bugs ou implemente novas features!
- 🎨 **Design**: Crie temas, ícones ou arte ASCII!
- 🌍 **Traduzir**: Ajude a localizar o Munux para novos idiomas!

---

## 🔧 Contribuindo com Código

### Processo de Desenvolvimento

1. **Faça um Fork** do repositório.
2. **Clone** seu fork localmente.
3. **Crie uma branch** para sua alteração (`feature/minha-feature`).
4. **Faça suas mudanças** e teste com `cargo test`.
5. **Formate seu código** com `cargo fmt`.
6. **Verifique lints** com `cargo clippy`.
7. **Envie um Pull Request** detalhando suas mudanças.

---

## 📋 Convenção de Commits

Usamos [Conventional Commits](https://www.conventionalcommits.org/):

| Tipo | Descrição | Exemplo |
|:-----|:------------|:--------|
| `feat` | Nova funcionalidade | `feat: suporte ao comando SSH` |
| `fix` | Correção de bug | `fix: cálculo de XP corrigido` |
| `docs` | Documentação | `docs: atualiza guia de instalação` |
| `refactor` | Refatoração | `refactor: simplifica lógica do parser` |

---

## ✅ Checklist para Pull Request

- [ ] Código compila sem erros.
- [ ] Todos os testes passam (`cargo test`).
- [ ] Sem avisos do Clippy.
- [ ] Código formatado com `cargo fmt`.
- [ ] Mensagens de commit seguem a convenção.
